# ポジショニング管理システム

日付・時間帯ごとの勤務予定を管理し、勤務中のクルーを各ポジションへ配置するためのデスクトップアプリケーションです。

クルーの登録、勤務時間の編集、時間帯ごとのポジション配置を一つのシステムで行うことで、シフトマネージャーの配置作業を分かりやすくすることを目的としています。

## 主な特徴

- カレンダーから管理する日付を選択できる
- クルー名、出勤時間、退勤時間を登録できる
- 登録した勤務予定を編集・削除できる
- 時間帯ごとに勤務中のクルーを確認できる
- ドラッグ＆ドロップでクルーをポジションへ配置できる
- 配置済みのクルーを別のポジションへ移動できる
- 作成したポジショニングを保存できる
- 前後の時間帯へ移動しながら配置を確認・変更できる

## 使用技術

| 項目 | 内容 |
| --- | --- |
| 言語 | Python |

## 動作環境

本システムの実行には、以下の環境が必要です。

- Python 3
- pip
- Tkinter
- tkcalendar

Tkinterは、通常のWindows版Pythonに含まれています。

## セットアップ

### 1. リポジトリを取得する

PowerShellまたはコマンドプロンプトで、次のコマンドを実行します。

```powershell
git clone https://github.com/shenghutengben-jpg/psp4.git
```

取得したプロジェクトの`positioning_system`ディレクトリへ移動します。

```powershell
cd psp4\positioning_system
```

### 2. 仮想環境を作成する

```powershell
python -m venv .venv
```

PowerShellを使用する場合は、次のコマンドで仮想環境を有効化します。

```powershell
.\.venv\Scripts\Activate.ps1
```

実行ポリシーにより有効化できない場合は、次のコマンドを実行します。

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

その後、再度仮想環境を有効化します。

```powershell
.\.venv\Scripts\Activate.ps1
```

仮想環境が有効になると、入力欄の先頭に`(.venv)`と表示されます。

### 3. 必要なライブラリをインストールする

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 4. システムを起動する

```powershell
python main.py
```

正常に起動すると、日付を選択するカレンダー画面が表示されます。

### 5. システムを終了する

アプリケーションは、画面右上の閉じるボタンから終了できます。

仮想環境を終了する場合は、次のコマンドを実行します。

```powershell
deactivate
```

## 基本的な使い方

1. カレンダーから管理する日付を選択する
2. クルー名、出勤時間、退勤時間を登録する
3. 必要に応じて勤務予定を編集・削除する
4. ポジション配置を行う時間帯を選択する
5. 対象時間帯に勤務しているクルーを確認する
6. クルーをドラッグ＆ドロップでポジションへ配置する
7. 作成した配置を保存する
8. 前後の時間帯へ移動し、配置を確認・変更する

## 主な機能

### 日付選択

カレンダーから対象日を選択します。日付を選択すると、その日の勤務予定を登録する画面へ移動します。

### 勤務予定の登録

選択した日付に勤務するクルーの名前、出勤時間、退勤時間を登録します。

初めて入力したクルー名はクルー情報として登録され、以降の勤務予定でも使用されます。

### 勤務予定の編集・削除

登録済みの勤務予定を選択し、クルー名、出勤時間、退勤時間を変更できます。

不要になった勤務予定は、一覧画面から削除できます。

### 時間帯選択

ポジション配置を行う時間帯を選択します。

選択した時間帯に勤務しているクルーだけが、ポジション編集画面に表示されます。

### ポジション配置

勤務中のクルーをドラッグ＆ドロップし、各ポジションへ配置します。

配置済みのクルーを別のポジションへドラッグすることで、配置を変更できます。

### ポジショニングの保存

保存ボタンを押すと、現在のポジション配置がJSONファイルへ保存されます。

### 前後の時間帯への移動

ポジション編集画面から前後の時間帯へ移動できます。

移動先の時間帯では、勤務時間外のクルーが一覧から除外され、新たに勤務時間内となったクルーが表示されます。

## 管理するデータ

| データ | 内容 | 主な項目 |
| --- | --- | --- |
| `Crew` | クルーの基本情報 | クルーID、クルー名 |
| `Schedule` | 日付ごとの勤務予定 | スケジュールID、対象日、クルーID、出勤時間、退勤時間 |
| `TimeSlot` | ポジション配置を行う時間帯 | 時間帯ID、開始時間、終了時間 |
| `Position` | クルーを配置するポジション | ポジションID、ポジション名 |
| `Assignment` | 日付・時間帯ごとの配置情報 | 配置ID、対象日、時間帯ID、ポジションID、クルーID |

勤務する日付や時間はクルーごとに変化するため、`Crew`ではなく`Schedule`で管理しています。

`Assignment`は、`Crew`、`TimeSlot`、`Position`を関連付けるデータです。

## ディレクトリ構成

```text
psp4/
├─ README.md
└─ positioning_system/
   ├─ main.py
   ├─ requirements.txt
   ├─ controllers/
   ├─ models/
   ├─ repositories/
   ├─ views/
   └─ data/
      ├─ assignments.json
      ├─ crews.json
      ├─ positions.json
      ├─ schedules.json
      └─ time_slots.json
```

各ディレクトリの役割は以下のとおりです。

| ディレクトリ | 役割 |
| --- | --- |
| `controllers` | 画面から呼び出される処理やデータ操作を管理する |
| `models` | Crew、Schedule、TimeSlot、Position、Assignmentを定義する |
| `repositories` | JSONファイルの読み込みと保存を行う |
| `views` | Tkinterを使用した各画面を定義する |
| `data` | システムが使用するJSONデータを保存する |

## 現在の仕様

- データはローカルのJSONファイルに保存される
- 1つのポジションに配置できるクルーは1人である
- ポジション編集はマウスによるドラッグ＆ドロップで行う
- 時間帯は1時間単位で管理する
- デスクトップでの利用を想定している

## 期待される効果

- クルーの勤務予定とポジション配置を一元的に管理できる
- 時間帯ごとの勤務状況を確認しやすくなる
- ドラッグ＆ドロップにより直感的に配置できる
- 保存した配置を後から確認・変更できる
- 紙や表計算ソフトを使用する場合と比べ、配置作業を行いやすくなる

## 今後の改善

次のような改善案が挙げられています。

- 1つのポジションへ複数人を配置する機能
- スマートフォンやタブレットでの操作対応
- ポジション名や配置可能人数を変更する機能
- 30分・60分など、時間間隔を設定する機能
- クルーごとの役割やスキルを管理する機能
- 対応できないポジションへの配置を防ぐ機能
- 登録済みクルーをプルダウンから選択する機能
- 勤務予定の重複登録を確認する機能
- 時間帯ごとの連絡事項を入力するメモ機能
- ログイン機能
- 保存済みポジショニングの履歴表示
- CSV出力・印刷機能
- 従業員がシフトを提出する機能

これらを追加することで、店舗や業種ごとの運用に合わせて、より使いやすいシステムに改善できると考えています。
